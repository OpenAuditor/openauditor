# Tasklane

Team task manager: projects, tasks, comments, AI summaries and Stripe billing.
Built with Next.js 16, Supabase and the Vercel AI SDK.

Demo app used for OpenAuditor evaluations. Not for production use.

## Setup

1. `npm install`
2. Copy `.env.example` to `.env.local` and fill in your Supabase and OpenAI keys
3. Apply `supabase/migrations` to your Supabase project
4. `npm run dev`
